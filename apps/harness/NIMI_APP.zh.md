# Nimi Harness

Nimi Harness 是一款原生接入 Nimi 的桌面端与网页伴侣工作台，面向多步骤的代码、文档与本地文件任务，提供透明的云端/本机模型路由和逐步可控的工具审批。

## 快速开始

1. 在受支持的桌面主机（**Windows x64** 或 **macOS arm64**）通过 Nimi Catalog 安装 **Nimi Harness**，登录 **Nimi Home**，并在 **Nimi Home → AI 模型** 中确保至少有一个可用的云端连接器或本机文本模型。
2. 从 Nimi Home 启动 **Nimi Harness**。点击左侧 **新建会话** 在独立默认会话目录中开始，或点击下拉菜单选择 **在本地目录新建会话…** 绑定现有项目文件夹。
3. 在输入框底部选择云端、本机或已保存模型（或沿用应用默认配置），按需拖入或附加最大 32 MiB 的文件，然后点击 **发送**。

## 会话中的核心工作流

- **云端、本机与已保存模型选择器**：在输入框打开模型选择器，按 **全部 / 云端 / 本机 / 已保存** 筛选或搜索模型。选择任意就绪的云端或本机模型时，应用会复用匹配的命名配置或为 Nimi Harness 新建命名配置，并仅绑定到当前会话。
- **配置变更冲突恢复**：若会话绑定的模型配置在 Nimi Home 中被外部修改（`AI_CONFIG_REVISION_CONFLICT`），对话内会显示确认提示条，一键即可采用最新配置并完整保留会话历史。
- **推理强度与会话指令**：当前模型支持时，可在输入框直接调整推理强度；在右侧 **工作区面板 → 会话与预设** 中查看上下文 Token 用量、编写会话级指令，或保存并复用常用指令预设。
- **逐步工具审批与权限模式**：默认的 **严格审批** 模式仅自动放行读取与搜索工具，写入文件、编辑文件、执行终端命令、抓取网页、转写音频及调用外部集成前均会展示差异（diff）或命令预览，由你选择 **仅允许一次**、**本会话均允许**、**提出修改意见** 或 **拒绝**。**自动编辑** 会自动放行工作区内的文件写入与编辑，命令与越界路径仍需审批；**只读规划** 会拦截所有写操作与终端命令。
- **文件浏览与附件**：直接拖入文件或点击 **附加文件**（单文件上限 32 MiB，PNG/JPEG/WebP 图片可发送给支持视觉的模型）。在右侧 **工作区面板 → 文件** 可实时预览文本、Markdown 与图片，将工作区文件附加到草稿，或在系统文件管理器中定位文件。
- **追问队列与随时停止**：任务运行期间可继续输入排队追问，或点击 **停止** 中止当前运行并撤回排队中的追问。

## 模型、音频、外部集成与 Home 联动

- **模型与权限设置**：通过左下角 **模型与权限** 查看当前 Nimi 账号与 Runtime 状态、切换界面语言或明暗主题、管理命名 AI 配置（含可选的 **语音转写 `audio.transcribe`**），并快速跳转到 Nimi Home 应用设置。
- **延续 Nimi Home 对话**：从 Nimi Home 导出对话（`nimi.home-chat.v1`）后，在侧边栏选择 **导入 Home 对话…** 即可承接历史上下文与未发送草稿，重复导入不会产生重复会话。
- **自动同步 Home 动态**：待审批提醒、任务完成与异常状态会自动推送到 **Nimi Home 动态（Activity）**，在 Home 点击对应动态可直接回到该会话。
- **外部集成工具**：在 Nimi Home 授权给 Nimi Harness 的外部服务会显示在 **工作区面板 → 集成** 中，调用时同样受会话权限模式与审批规则约束。

## 网页远程伴侣

当主 PC 上的桌面版 **Nimi Harness** 正在运行，且已在 Nimi Home 授权远程会话集成（`ai.nimi.harness.sessions.v1`）时，你可以从 [Nimi 官网应用页](https://nimi.ai/apps/harness) 或 [harness.nimi.xyz](https://harness.nimi.xyz/) 打开网页伴侣：

- 使用同一 Nimi 账号登录，首次连接时在主 PC 的 **Nimi Home** 中亲自确认该网页来源，并按需授予所需的会话操作权限。
- 在浏览器中浏览或新建 PC 会话、提交幂等任务、实时查看流式进度、审阅文件差异并按次允许或附带修改意见拒绝工具提案，以及上传/下载最大 32 MiB 的工作区文件。
- 参数超过 32 KiB 的工具提案需回到桌面端审阅。所有模型调用、文件读写与命令执行均留在你的主 PC 上；退出网页后重新连接即可读回同一持久化会话与工作区文件。

## 数据去向与隐私

- **PC 本地存储**：会话持久化记录（SQLite）和默认会话工作目录保存在本机 `~/.nimi-harness` 下，并按账号命名空间隔离。文件读写与已批准的命令使用你当前桌面系统用户的权限执行。删除会话仅清理沙盒会话目录，绝不会删除你绑定的本地项目目录。
- **Nimi 账号存储**：输入框草稿、指令预设、会话索引元数据与远程幂等回执存储在 Nimi Harness 的账号隔离 Nimi 存储中。
- **模型推理链路**：提示词、工具输出与可选的音频文件通过 Nimi Runtime 发送至当前会话所选的本机或云端模型。本机模型数据不出设备；云端模型仅通过你在 Nimi Home 配置的连接器接收当前轮次上下文。

## 当前限制与帮助

- **受支持的桌面平台**：桌面端安装包支持 **Windows x64** 与 **macOS arm64**，安装、升级与账号认证由 Nimi Home 管理。
- **网页伴侣前置条件**：网页端不在浏览器内直接执行文件工具或模型推理，使用前需确保主 PC 的 Nimi Home/Runtime 与桌面端 Nimi Harness 在线，并已授权 `ai.nimi.harness.sessions.v1`。
- **语音转写配置**：`transcribe_audio` 工具当前使用应用默认配置中的 `audio.transcribe` 路由。
- **移动端状态**：Android 伴侣端仍在验收中，未包含在本版本发布范围内。
- **获取支持**：如遇启动、连接或运行时问题，请前往 [github.com/nimiplatform/nimiapp-harness/issues](https://github.com/nimiplatform/nimiapp-harness/issues) 提交反馈，并附上 Harness 版本、操作系统与报错信息（请先去除凭据与私有文件内容）。
