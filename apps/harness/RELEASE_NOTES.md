# Nimi Harness 0.2.0

Initial public desktop release for **Windows x64** and **macOS arm64**, paired with the hosted **Web companion** (`ai.nimi.harness.sessions.v1`).

## Highlights
- Multi-session desktop workspace powered by durable SQLite transcripts and isolated or bound local project folders.
- Cloud, Local, and Saved model picker with per-session named configuration binding, reasoning effort control, and one-click conflict recovery.
- Step-by-step tool approval with unified diff previews, permission modes (`Strict`, `Auto-Edit`, `Plan Only`), session tool allowlists, and automatic Nimi Home Activity notifications.
- Workspace file inspector with live Markdown, code, text, and image previews plus Nimi Home chat handoff import (`nimi.home-chat.v1`).
- Remote session provider (`ai.nimi.harness.sessions.v1`) enabling browser-based task submission, live progress streaming, remote tool diff approval, and workspace file transfer up to 32 MiB.
