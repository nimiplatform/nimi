# NimiGo 使用指南

把零散的资料、想法与项目，一步步推进为可随时取用的成果。

## 开始第一项工作

1. 在左下角选择一位已有的 Nimi Agent 作为工作搭档。
2. 创建项目与工作，写清受众、目标、核心内容与约束条件。
3. 添加文本或 Markdown 资料，选择适用的工作方法，点击“交给搭档开始”。
4. 查看推进步骤，回答搭档提出的必要问题，等待成果保存。

### 交付状态与上下文规则

- **已交付与待交付**：“已交付”代表搭档已实际保存成果，或完成了经你审核确认的业务修改。如果搭档仅在对话中回复而未保存正式结果，工作会保持“待交付”。任务失败或手动停止时，此前已保存的成果依然保留。
- **继续委托的上下文**：补充回答或继续委托时，搭档会参考当前工作近期已保存的交流（如先前约定的受众与语气），但只会带入有限长度的前文；超长内容会自动省略并向搭档注明。当前的目标、资料和本次要求始终优先于历史记录，不会重复执行旧委托。
- **修改项目与工作**：选中项目后点击“编辑项目”，可调整项目名称和共享背景，搭档在执行该项目下的每项工作时都会参考这些信息。在工作详情中可修改名称、目标、归属项目和工作方法；打开资料即可修订内容。一旦修改了目标、方法或资料，工作会回到“待开始”状态，同时保留已有成果与执行记录。修订来自生态应用的资料时，系统会保留原始出处并标明“用户修订”，仅修改当前工作中的副本。

## 查看、修订和带走成果

在工作侧栏、“最近成果”或“成果库”中即可打开文档：

- **编辑与改进**：点击“编辑”可保存为新版本，历史版本不会被覆盖。点击“交给搭档改进”会自动带入最新保存的版本，确认或补充要求后即可发送。
- **定位本地文件**：点击“在文件夹中显示”可直接定位到本地 Markdown 文件，方便复制或移作他用。
- **跨应用引用版本**：选定某个已保存版本后，点击“复制版本引用”，即可粘贴到 NimiDay 等生态应用的资料入口中。引用绑定的是你选中的特定版本；后续即使保存了新版本，也不会改动这条引用，确保其他应用读取到的内容始终固定可预期。

## 回来继续工作

重新回到工作台时，顶部会优先展示“需要你处理”和“最近成果”，方便快速接上进度：

- **排队中的工作**：重新打开应用后保持为“待开始”，已添加的资料和要求完整保留，等你确认后再手动启动。
- **状态待确认**：若因网络波动或程序重启导致执行状态未决，工作卡片会标记“待确认”。请先核对执行结果与已有成果，再决定继续推进还是重新发起，系统不会盲目自动续跑。
- **重试委托**：如果任务执行失败，点击“重试这次委托”会直接沿用刚才补充的要求再次尝试，无需重新输入。

## 把好做法沉淀为方法

完成一项工作后，可以点击“提炼为方法”，整理步骤与交付标准并复用到新工作中。方法保存在当前工作空间下，更换搭档后依然可用。来自不同安装来源的工作空间各自独立保存，不会自动合并。

## 外部连接、后台运行与独立交流

- **读取集成资料**：在工作详情中可使用已授权的外部连接获取素材。点击“读取集成资料”即可将外部内容保存为工作素材，再交由搭档梳理分析。所有敏感凭据均由 Nimi 统一保管，不会暴露给第三方应用。
- **后台推进与退出**：已经开始的分析任务在关闭窗口后仍会在后台继续运行，在实际保存成果版本后按你的偏好发送通知。如需彻底结束运行，可在菜单中选择“退出并停止 NimiGo”。
- **工作交流与日常记忆隔离**：工作交流通过独立的业务通道执行并保存在 NimiGo 内，不会与搭档的日常闲聊记忆混在一起。如需语音沟通，可点击语音入口发起通话。

## 每日例行与消息提醒

每日例行任务需要 NimiGo 窗口与 Nimi 同时保持运行；多个例行任务会按加入顺序排队执行。你可以随时暂停例行，或手动立即开始。例行成果交付后可在 Nimi Home 中查看通知，点击即可直接跳回对应工作。

## 生态来源与桌面搭档（Avatar）

- **生态来源**：在“生态来源”中可为项目勾选要关注的应用来源，搭档查询资料时也会遵循这一范围。选中已有工作中的内容后，既可以直接加入当前资料，也可以带入新工作，原始出处与更新时间均会完整保留。
- **Avatar 协同**：桌面 Avatar 会自动交接给当前工作的同一位搭档。发起语音对话前，需先为对应 Agent 配置好可用音色和实时对话设置；工作回复保存在 NimiGo 中；语音使用伙伴独立的 Nimi 对话。

## 中断与异常处理

- **随时停止任务**：你可以随时停止正在执行的工作。停止前已保存的成果版本会完整保留，且不影响这位搭档在其他工作中的进度。
- **核对正式成果**：只有实际保存到文档库中的版本才算正式交付。如果搭档只在对话里给出了建议草稿，可在确认后让它保存为正式版本；遇到中断并提示“待确认”时，请先核实上一步的执行结果，再决定继续或重试。
- **服务重连**：若界面提示 Runtime 暂不可用，待 Nimi 恢复连接后可按界面提示重新尝试当前工作。
