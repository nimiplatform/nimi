# NimiGo 使用指南

把资料、想法与项目，推进到可以继续使用的成果。

## 开始第一项工作

1. 在左下角选择一位已有的 Nimi Agent 作为工作搭档。
2. 建立项目和工作，写清受众、目标、需要包含的内容与约束。
3. 添加文本或 Markdown 资料，选择适用的工作方法，再点击“交给搭档开始”。
4. 查看推进步骤，回答搭档提出的必要问题，等待成果保存。

“已交付”表示实际保存了成果或完成了经你审核的源业务修改。若搭档只是回复而没有保存，工作会显示“待交付”；失败或停止时，已有成果仍然保留。

补充回答和继续委托会参考这项工作已保存的近期交流，包括此前明确的受众、语气等要求。只带入当前工作的有限前文；过长内容会省略并向搭档标明。当前目标、资料和本次要求优先于历史交流，不会重新执行旧委托。

选中项目后可以“编辑项目”，调整名称和共同背景。搭档执行每项工作时会参考这些背景。工作详情中可修改名称、目标、归属项目和方法；打开资料后可以修订内容。修改目标、方法或资料会让工作回到“待开始”，保留已有成果与执行记录。来自生态来源的资料修订会保留出处、标明“用户修订”，只修改工作中的副本。

## 查看、修订和带走成果

在工作侧栏、“最近成果”或“成果库”打开文档。点击“编辑”后保存新版本，原版本保留。再点“交给搭档改进”，继续委托中会带出最新保存的版本；确认或补充要求后发送。点击“在文件夹中显示”可定位到实际 Markdown 文件，方便复制与使用。

选定已保存版本后，点击“复制版本引用”，可粘贴到 Day 的 Go 资料入口。引用包含精确的工作、成果和修订 ID，并附上标题与版本供辨认；高级详情保留三项 ID。标题和版本提示不替代真实读取结果，未保存的修改不包含在引用中。

## 回来继续工作

工作台先列出“需要你处理”和“最近成果”，下面按最近更新时间排列工作。需要回答、执行失败、结果待确认，以及离开前未开始的排队委托都有继续入口。

排队时尚未提交的工作，重开后回到“待开始”，保留资料和本次追加要求，由你手动开始，不自动续跑。已经提交但结果不明的工作保持“待确认”，先核对结果；只有确切记录的那一轮可以停止。取消未获确认时会继续显示“待确认”，不会把本地停止推进说成执行已取消；若该轮已经结束，则保留实际终态。失败后“重试这次委托”沿用本次要求，不退回最初的交付目标。

## 把好做法用到下一项工作

完成一项工作后，可以“提炼为方法”，调整做法与交付标准，再用于新工作。方法属于工作空间，更换搭档后仍可使用。不同安装来源的工作空间分别保存，不会自动合并。

## 连接、后台与成果读取

在工作详情选择已经获准的连接读取操作；这项工作固定使用所选连接，不会因默认账户更换而转用另一账户。集成的连接和持续许可在 Nimi 中管理。原始凭据不进入 Go。选好读取操作后，可用“读取集成资料”直接取得并保存素材，无需 Agent；高级参数保留提供方的输入说明。随后再把已保存的材料交给搭档分析。

已开始的分析在关闭窗口后由 Go 的执行部分继续，保存真实成果版本并按偏好发布消息。菜单中的“退出并停止 NimiGo”结束整个执行主体；停止或会话真正失效后不自动恢复。窗口重开连接正在运行的同一份 App 工作状态。

成果版本详情可复制精确读取引用。获准的 Day 等应用通过 Go 的公开成果操作读取该版本；Go 停止后操作不可用，平台不会代读 Go 的资料。

工作交流通过独立 Agent 业务入口执行，保存在 Go；不自动成为规范聊天、聊天摘要或对话记忆。用户显式打开语音聊天时使用同一 Agent 的规范聊天入口。

## 例行与消息

每日例行需要 NimiGo 窗口与 Nimi 保持运行；忙碌时按加入顺序排队，每次执行一项。执行期间可以建立其他工作并加入队列，也可以停止尚未开始的排队工作。关闭期间错过的工作不会自动补跑。你可以暂停例行，或手动开始。交付结果可进入 Nimi Home，点击后返回对应工作。

## 生态来源与桌面搭档

“生态来源”可为项目选择关注的应用来源，搭档查询时也沿用该范围。默认收起 Agent 对话动态；可以显式显示、搜索已载入内容或加载更多。选择一项已有工作后可直接加入资料，也可以带入新工作，出处与更新时间都保留。未载入不代表不存在，完整业务状态仍需在来源核对。

World Studio 摘要修改会先展示前后对照，只有你选择应用且来源授权有效时才写回；打开来源不会将原事项标为完成。

Avatar 会交接给当前同一位搭档。显式语音聊天需要这位 Agent 已有可用的声音和实时对话配置；工作回复保存在 Go，不借用聊天记录生成朗读。无法使用时，请先在 Nimi 检查对应设置。

## 遇到中断

停止只针对这项工作已记录的执行轮次，不影响搭档后来开始的其他工作。停止之后到达的旧工具结果不会继续新增成果或修改下一项工作，停止前已经保存的版本保留。重开后若显示“待确认”，先核对执行结果与已有成果，再决定停止未决执行或重新委托。不要把模型的口头承诺当作已经完成的修改。

会话失效时，旧窗口中的状态会被丢弃，并从当前受保护范围重新加载。未保存的旧范围修改不会自动带到另一个账号。若新窗口显示 Runtime 暂不可用，等 Nimi 恢复后使用现有的重试入口；这不会补跑旧业务。
