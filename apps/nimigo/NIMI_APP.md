# NimiGo

NimiGo 帮你与 Nimi 搭档一起，把零散的资料、想法与跨应用素材，一步步整理成可编辑、可复用的文档成果。

## 你可以做什么

- **按项目推进工作**：围绕具体项目建立工作项，明确受众、目标、核心内容与约束条件，交由搭档梳理资料并起草成果。
- **版本化管理成果**：在工作侧栏、“最近成果”或“成果库”中查看文档。点击“编辑”可保存为新版本而不覆盖历史；点击“交给搭档改进”会基于最新已保存版本继续迭代；点击“在文件夹中显示”可在本地直接取用 Markdown 文件。
- **跨应用固定引用**：选定某个已保存版本后点击“复制版本引用”，可粘贴到 NimiDay 等生态应用中。引用始终绑定你选中的特定版本，后续保存新版本不会改变其他应用读取到的内容。
- **提炼并复用方法**：完成工作后点击“提炼为方法”，可将推进步骤与交付标准保存在当前工作空间下，供新工作复用；更换搭档后方法依然保留（不同安装来源的工作空间各自独立保存）。
- **联动生态与外部资料**：在“生态来源”中为项目勾选关注的应用来源，或通过“读取集成资料”将已授权外部连接中的内容保存为工作素材。引用或修订生态应用资料时，系统会保留原始出处与更新时间，并在当前工作中标记“用户修订”副本，不改动原应用数据。

## 开始第一项工作

1. **选择工作搭档**：在左下角选择一位已有的 Nimi Agent。
2. **创建项目与工作**：新建项目（可通过“编辑项目”填写共享背景），并在项目下创建工作，写清目标与要求。
3. **添加资料并启动**：放入文本、Markdown 素材或导入外部资料，选择适用的工作方法，点击“交给搭档开始”。
4. **回答问题并确认交付**：查看推进步骤，补充搭档提出的必要问题，并核对成果是否已正式保存到成果库。

## 接续工作与调整范围

重新打开工作台时，顶部会优先展示“需要你处理”和“最近成果”：

- **继续委托的上下文**：补充回答或继续委托时，搭档会参考当前工作近期已保存的交流，但只带入有限长度的前文（超长部分自动省略并注明），且始终以当前的目标、资料和本次要求为准，不会重复执行旧委托。
- **修改目标或资料**：在工作详情中修改目标、工作方法或资料内容后，工作会回到“待开始”状态，此前已保存的成果版本与执行记录仍会保留。
- **排队、待确认与重试**：重新打开应用后，排队中的工作保持为“待开始”，等你确认后再手动启动。若因网络波动或程序重启使工作标记为“待确认”，请先核对已有成果与执行结果，再决定继续推进或点击“重试这次委托”（重试会自动沿用上一次补充的要求）。

## 运行、数据与费用

- **正式交付与草稿的区别**：搭档的可用能力、角色设定，或仅在对话中给出的建议草稿，**都不代表任务已成功交付**。只有实际保存到成果库中的版本，或经你审核确认完成的业务修改，才会使工作进入“已交付”状态；若搭档只在对话中回复了草稿，请先核对并让它保存为正式版本。
- **每日例行与后台运行条件**：
  - **每日例行**：每日例行任务受运行条件约束，需要 NimiGo 窗口与 Nimi 同时保持运行才会按序触发；你可以随时暂停例行或手动立即开始。成果保存后可在 Nimi Home 通知中查看并跳回对应工作。
  - **后台推进与完全退出**：已开始的任务在仅关闭窗口时仍会在后台继续运行，并在保存成果版本后按偏好发送通知；如需彻底停止后台运行，请在菜单中选择“退出并停止 NimiGo”。
- **停止任务的限制**：你可以随时停止正在执行的工作，停止前已保存的成果版本会完整保留，且不影响该搭档在其他工作中的进度。但停止任务只能终止后续步骤，**不能撤回已经发生的外部操作或已经生效的业务修改**。
- **桌面 Avatar 与外部凭据配置**：
  - **桌面 Avatar 与语音**：桌面 Avatar 会自动交接给当前工作的同一位搭档。发起语音对话前，需先为对应 Agent 配置好可用音色和实时对话设置。
  - **外部连接凭据**：通过“读取集成资料”访问外部服务时，这些集成连接的凭据由 Nimi 托管，App 通过已授权的接口使用连接。
- **本地存储、云端推理与费用说明**：
  - **本机数据与对话记录**：项目、素材、成果文档及工作交流均保存在本机设备；工作交流通过独立通道保存在 NimiGo 内，不作为伙伴在 Nimi 中的聊天记录；显式语音通话则使用同一位伙伴的 Nimi 对话。
  - **云端服务与费用**：业务数据保存在本机设备，**不意味着模型推理都在本机进行**。当你选择云端模型、语音服务或使用外部集成时，执行任务所需的资料与上下文会发送给相应的服务提供方，并可能产生相应费用。
- **故障排查**：若界面提示 Runtime 暂不可用，待 Nimi 恢复连接后可按提示重试；如需在 Nimi Home 中排查连接或环境问题，可前往 **设置 > 故障排查**（版本信息位于 **帮助 > 关于**）。
