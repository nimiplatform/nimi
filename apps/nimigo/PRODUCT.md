# NimiGo

NimiGo 是专为项目推进与成果沉淀打造的智能工作空间。你可以指派由 Nimi 托管的角色作为工作搭档，共同完成项目规划、资料整理、内容创作与成果交付。项目相关的文档资料完整保留在本地工作空间内，而角色的个性人设与长期记忆则由 Nimi 核心统一维护。

## 核心使用流程

1. **指派搭档与建立项目**：在界面左下角选择你的 AI 搭档，创建新项目并设定明确的阶段交付目标。
2. **组织资料与工作方法**：添加文本或 Markdown 参考资料，选择现有的或自定义工作方法（Prompt / Workflow），启动搭档协同。
3. **实时跟进与协同交互**：查看每一步执行过程，在关键节点补充信息或回答提问，必要时可暂停或终止任务。搭档生成的文档在保存后正式纳入交付成果库，确保结果切实落地。
4. **成果查看与版本迭代**：在成果库中查阅交付物，直接编辑并保存新版本；历史版本完整保留，支持在本地文件管理器中定位，或交给搭档进行二次优化。
5. **工作法提炼与例行执行**：将验证有效的优质工作流程提炼为通用方法，复用到其他工作，或配置为每日例行任务推进（例行任务执行期间需保持 NimiGo 窗口打开）。

## 核心机制与设计原则

- **上下文与任务编排**：每次委托均自动装配当前项目背景与关联资料。任务支持灵活修订名称、目标与工作方法；修改任务输入时安全重置待办状态，已生成的成果与历史执行记录均妥善保留。任务队列遵循先入先出执行，添加新任务不会阻塞界面交互。
- **跨应用与生态打通**：通过标准的 Activity 协议无缝关联生态外部源对象；支持加载 World Studio 中的场景与设定资料，所有外部修改需明确确认并由 Realm 完成权限校验。
- **具身化与语音交互**：支持通过当前 Agent 的 Avatar 具身化组件进行面对面交互，语音对话直接复用系统的 Conversation / Realtime 引擎配置。
- **本地优先与数据隔离**：项目、方法、工作记录与文档版本统一保存在应用私有存储中。数据由应用在当前账号下安全隔离持久化，确保隐私与数据自主可控。

## 本地开发与调试

本项目位于 Nimi 主仓的 pnpm workspace 中，共享根依赖与构建系统，通过 `workspace:*` 引用 SDK、Kit 与 App Tools。

### 启动开发环境

日常开发前，确保已在主仓根目录启动底层服务：

```sh
# 终端 1：启动 Runtime
pnpm dev:runtime

# 终端 2：启动 Desktop
pnpm dev:desktop
```

随后在主仓根目录下启动 NimiGo：

```sh
# 枚举已有注册实例
pnpm dev:nimigo -- --list-registrations

# 续接指定实例启动
pnpm dev:nimigo -- --resume <selector>
```

首次运行可直接执行 `pnpm dev:nimigo` 进行初始化注册。日常迭代建议通过 `--resume` 续接已有实例，以保证测试数据与配置的连续性。

### 代码检查与构建

在主仓根目录下执行：

```sh
pnpm --filter @nimiplatform/nimigo typecheck
pnpm --filter @nimiplatform/nimigo test
pnpm --filter @nimiplatform/nimigo build
```
