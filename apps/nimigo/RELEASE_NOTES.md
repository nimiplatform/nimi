# NimiGo 0.1.1 · 本地候选

- 窄窗保留项目切换、新建项目、Avatar 和偏好入口，并为图标按钮补充可访问名称。
- Avatar 切换使用应用内确认，保留当前伙伴时不改变桌面呈现。
- Home 的使用说明改为面向用户的产品指南；安装版实测完成真实成果交付与文件定位。
- 项目与多事项工作台，任命并恢复现有 Agent，保留资料和岗位方法。
- Runtime 主导的真实技能调用：资料查阅、步骤整理、补充提问、成果保存与版本修订。
- 工作项停止携带精确轮次校验；旧请求不影响同一 Agent 的后续工作，未决执行可以主动核对。
- Markdown 成果库、手动编辑、文件定位与再次委托。
- 生态 Activity、World Studio 来源查询，以及用户审核后的世界摘要修改。
- 可暂停的每日例行、关闭期间错过提示和 Home 结果入口。
- 同一 Agent 的 Avatar、Realtime 与最终语音协作入口。

运行条件、实际验收与当前限制以本工程的交付摘要为准。本地候选不代表公开发布、Registry 准入或其他平台已验收。
