# Archived Nimi Simulator

Simulator was retired on 2026-09-17. This directory preserves its source,
selected-source configuration, App preview adapters and tests, and App Tools
conformance implementation under their original repository-relative paths.

These files are historical reference, not a runnable workspace or active
product authority. They are excluded from current development, package
publication, CI and release checks. Relative imports and package declarations
describe the former repository layout; they are not maintained here.

The active Desktop, Lab and Zhiyu renderers and generic SDK/Kit testing and
host boundaries remain in their existing owners. Simulator-specific manifests,
adapters, conformance exports and `nimi-app check --conformance simulator`
have been removed from the active surface without compatibility aliases.

Canonical retirement records remain in `.nimi/spec/**`. Code under `apps/`
retains its MIT license; archived App Tools code retains Apache-2.0.
