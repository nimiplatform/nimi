# 远程写作台

使用自己 PC 上的 Nimi Runtime 起草文字，支持本地模型，也可引用该 PC 上已配置的 Cloud Connector。

“文本标注任务”用于演示持久 AI 任务的提交、查询与明确取消。请先在 PC 上准备好相应的本地能力，再为写作台选择 Local 文本标注。响应中断时可按提交编号查询，不会自动再次提交；取消请求的结果以 Runtime 返回的实际状态为准。

## 开始使用

1. 创建或登录写作台自己的账号，再点击“通过 Nimi 登录”，在 Nimi 官方网页验证希望关联的账号。不要将 Nimi 密码填写到写作台。
2. 在主机 Home 登录同一 Nimi 账号，绑定主 Runtime，启用远程接入。此网站首次请求连接时，在 Home 确认网站来源和能力。
3. 回到写作台连接 PC，为此网站保存文本生成配置，然后输入要求、开始生成。

此网站必须先获得生态来源登记。没有登记时，Nimi 会拒绝接入；网站登录成功并不代表 Runtime 已允许访问。

## 配置与数据

网站账号和 Nimi 关联保存在网站服务器。Nimi 接入会话由网站后端保管，网站不接收 Nimi 密码或主机管理凭据。

提示词和生成内容在浏览器与 PC 之间直连传输，草稿仅保留在当前页面。使用 Cloud Connector 时，PC 会按用户配置向相应云服务发送请求。此网站只能更新当前用户在自身 App 下的 AIConfig，不能修改公共模型或云服务凭据。

## 限制和帮助

主机 Home、Runtime 和当前浏览器页面需要保持运行。无法直连时，当前版本不提供服务器转发。网络中断会结束实时生成，不会自动再次提交；可以重新连接后主动发起新请求。

退出或切换网站账号时，旧 Nimi 使用上下文失效；解除关联后需重新通过 Nimi 登录。断开当前页面的连接不会停止主 Runtime。

此参考站点用于开发和接入验收，运行与来源登记说明见 README。Android 真机验收与此网站验收分别记录。
