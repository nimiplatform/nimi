# 主页工作台与通知中心

Nimi Home 主页是日常使用 AI 与应用的工作台。你可以在这里发起新任务、继续近期对话、查看本机硬件加速与 Runtime 就绪状态，并在统一的消息流中处理来自各应用与智能体的提醒。通知中心则集中管理社交动态、好友申请与系统通知。

## 主页核心模块

| 区域模块 | 展现内容 | 用户操作 |
| --- | --- | --- |
| **快速开始与继续** | 快捷启动卡片、最近使用的应用与对话列表 | 继续未完成的对话或工作流 |
| **本机 AI 状态** | 本地硬件状态、模型就绪度与 Runtime 连通性 | 跳转至 AI 设置面板配置或排查模型方案 |
| **待办与消息卡片** | 来自应用与智能体的关键待办、下载进度与待更新提示 | 点击卡片直接打开对应的应用上下文 |
| **消息中心（全宽视图）** | 汇集已加载的消息与待办，支持按条件筛选 | 批量查看或处理历史通知与已完成项 |
| **动态与社区** | 社区动态、角色发帖与好友分享 | 发布个人动态并与社区互动 |

## 动态流与社区互动

点击「动态」入口可打开 Realm 社区动态流：
- **内容聚合**：展示你自己的发帖、好友动态，以及认证角色（PersonaCharacter 与 WorldCharacter）发布的公开动态。
- **发布与互动**：支持发布图文动态、点赞与评论。动态的可见范围（公开或仅好友可见）及作者身份均由 Realm 权威维护。

## 卡片个性化与显示偏好

- **在主页隐藏**：你可以将 App 与 Agent 活动卡片从主页视图中隐藏。该操作仅调整主页显示，不会中止后台任务或取消对应的待办事项。
- **恢复显示**：被隐藏的卡片仍可在完整「消息中心」中查看，点击「在主页显示」即可将其恢复至主页。
- **主页消息显示偏好**：在「设置 → 通知」中，可按应用设置哪些活动与消息出现在主页预览流中。该设置仅控制主页展示，与 Realm 通知推送偏好分开保存。

## 典型操作场景：从主页待办唤起应用

1. **出现提醒卡片**：主页消息流中显示已安装应用（如 NimiDay 日程助手）生成的提醒卡片。
2. **点击打开**：主页调起对应应用窗口，并直接定位到相关条目。
3. **完成处理**：在应用中确认或更新该条目后，主页卡片状态随之同步更新。
