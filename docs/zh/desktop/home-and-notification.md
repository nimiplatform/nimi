# 主页工作台与通知中心

Nimi Home 的主页是用户的个人 AI 仪表盘。用户可以在这里快速开始新的任务或继续先前的对话，查看本机的 AI 运行状态与服务健康度，并在统一的消息流中掌握近期的关键事件。通知中心则集中归集所有社交动态、好友申请与系统提醒。

## 主页核心模块

| 区域模块 | 展现内容 | 用户操作 |
| --- | --- | --- |
| **快速起步与历史继续** | 快捷入口卡片、最近使用的应用与对话列表 | 一键唤醒上次未完成的对话或工作流程 |
| **本机 AI 状态** | 当前硬件加速支持情况、本地模型就绪度与 Runtime 连通性 | 快速进入配置面板排查或调整模型 |
| **待办与消息卡片** | 来自本地 App 与智能体的关键待办、下载任务进度与可用更新 | 点击卡片直达对应应用或具体消息上下文 |
| **消息中心（全宽视图）** | 聚合所有应用待办与事件流，支持按来源、处理状态筛选 | 集中批量管理待办与历史提醒 |
| **动态广场** | 浏览全平台的精彩动态与关注好友的最新分享 | 快捷发布个人动态与交流互动 |

## 动态流与社区互动

点击“动态”入口可打开 Realm 社区动态广场：
- **内容聚合**：包含用户自己的帖子、好友分享的动态，以及经过认证的公共角色（PersonaCharacter / WorldCharacter）的精彩内容。
- **发布与互动**：用户可发布图文动态、点赞与评论。内容的可见范围（公开/仅好友）与作者身份归属由 Realm 统一保证真实性。

## 卡片个性化与显示偏好

- **在主页隐藏**：用户可选择在主页隐藏某些不常关注的应用卡片，这仅影响主页的视觉呈现，不会中止应用后台任务或清空待办。
- **重新唤醒**：在「消息中心」中可随时查看被隐藏的内容，并点击“在主页显示”将其恢复至主面板。
- **主页消息显示偏好**：在「设置 → 通知」中，用户可以按应用选择哪些消息在主页卡片流中显示。此设置仅控制主页内容呈现，独立于 Realm 系统通知接收设置。

## 典型操作场景：从主页待办唤起应用

1. **收到任务待办**：主页消息栏中出现某款应用（如 NimiDay 日程助手）生成的日程提醒卡片。
2. **点击卡片**：主页自动唤起对应的应用窗口，并精准定位至该条日程详情。
3. **完成处理**：用户在应用中确认或修改日程后，卡片状态同步刷新。
