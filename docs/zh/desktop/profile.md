# 个人资料与主页

在 Nimi 桌面端中，「个人主页（Profile）」是展示与编辑你个人形象的核心入口。在这里，你可以自由修改显示名称、更换头像、编写个性签名，并查看你拥有的 Agent 智能体以及你创建或探索过的数字世界。在全平台的各个世界与应用中，你的资料均保持统一。

## 个人主页包含的内容

| 资料字段 | 来源与作用 | 是否可编辑 |
| --- | --- | --- |
| **显示名（Display Name）** | 在所有聊天、评论及动态中展示的名称 | 可随时修改 |
| **头像（Avatar）** | 个人形象图标，存储于 Realm 分布式资源库 | 可随时更换 |
| **个性签名（Bio）** | 简短的自我介绍 | 可随时修改 |
| **用户核心 ID（Account ID）** | 账户创建时固定的唯一加密身份标识 | 永久固定，不可修改 |
| **拥有的 Agent 列表** | 由该账户创建并管理的专属智能体 | 随 Agent 创建与配置自动同步 |
| **创建与访问的世界** | 用户作为 Creator 建立的世界及近期的足迹 | 自动随世界互动记录更新 |

个人资料数据由 Realm 统一存储并同步至云端与多设备。在桌面端保存修改后，改动会即时广播至你参与的所有世界与应用中。

## 场景化预览与隐私保障

在桌面端的其他界面（如群聊成员列表、动态作者卡片、探索流），其他用户查看你的资料时，系统通过标准只读接口仅呈现公开可见的信息：
- **公开可见**：显示名、头像、个性签名，以及你设为“公开可见”的世界与 Agent。
- **隐私受控**：你的私密好友列表、私有 Agent 配置及账户底层设置均不会泄露给其他访客。

## 典型操作场景：修改个人资料

1. **进入个人主页**：在桌面端左下角或右上角点击个人头像，进入「个人主页」。
2. **编辑信息**：点击“编辑资料”，修改昵称或上传新的头像图片。
3. **保存并同步**：点击“保存”，系统通过 SDK 将更新提交至 Realm 服务。
4. **全端生效**：新资料即时在所有已打开的会话、好友的聊天界面及动态流中同步更新。
