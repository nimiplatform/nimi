# 社交关系与好友网络

在 Nimi 桌面端中，社交关系没有被隔离在单独死板的“通讯录”页面里，而是自然融入在用户实际交互的各个场景中：用户个人资料、聊天中的好友侧栏、Explore 探索流中的发现卡片，以及系统的通知中心。

社交关系的状态由 Realm 集中维护。桌面端负责在交互上下文中呈现当前的关系状态并捕获用户操作（如加为好友、屏蔽用户），随后通过 SDK 安全同步给底层服务。

## 场景化呈现与操作入口

| 交互场景 | 呈现与操作能力 |
| --- | --- |
| **个人资料详情** | 查看关系状态（好友/未添加/已拉黑）、发送好友请求、解除好友或屏蔽 |
| **聊天侧栏** | 在当前会话上下文中快速查看可联系的好友与公开 Agent |
| **探索（Explore）与发现流** | 在浏览社区内容或公开角色时，一键发送关注或好友申请 |
| **通知中心** | 集中处理收到的好友申请，支持快速通过、忽略或查看对方资料 |
| **智能体配额检查** | 检查当前账户的 Agent 好友额度及 LocalAgent 启动前置条件 |

这种设计让社交互动随处可见，无需在不同页面之间频繁跳出。

## 全平台统一的社交状态

在 Nimi 的世界网络中，好友关系是跨世界通用的。一旦两位用户成为好友，该关系在二人共同参与的每个数字世界以及共同使用的 Nimi 应用中均保持一致与同步：

- **数据存储**：由 Realm 统一存储并保证跨端一致性。
- **跨世界与跨应用可见**：无需在每个新世界中重复添加好友。
- **权限安全**：好友请求、接受与屏蔽均通过结构化契约严格校验，防止伪造与越权。

## 典型操作流程

### 1. 发起与接受好友申请
1. **浏览资料**：在探索流或聊天中点击某位用户的头像，展开其个人资料。
2. **发送申请**：点击“添加好友”，桌面端通过 SDK 向 Realm 发送结构化的好友请求。
3. **接收通知**：对方在通知中心实时看到带有申请附言的卡片。
4. **通过申请**：对方点击接受后，双方关系立即更新为好友，并在双方的所有应用与会话中即时生效。

### 2. 屏蔽与隐私保护
若需停止与某位用户的交互，可在其资料卡中选择“屏蔽”。系统将该用户的屏蔽记录提交至 Realm。生效后，双方将无法在任何应用或世界中发起直接会话或查看私有动态，全面保障个人隐私与空间安全。
