# 创作者经济

## 状态：现在 (Running today)

Realm 经济契约 (R-ECON-*) 已交付；通往创作者收益政策的桥接已准入。完整的支付管线叙事见 [创作者收益](/zh/realm/creator-payouts)。

创作者经济是 Realm 经济中关于世界创作者变现的那一部分：礼物和购买产生的收入事件、分成方案、结算、提现。世界创作者经济和创作者收入策略这两份文件在外部开放规范锚点和本地经济契约之间搭起一座桥。

## 创作者经济归在哪里

| 表面 | 权威 |
| --- | --- |
| Realm 经济 | `R-ECON-*`，append-only 经济事件流 |
| 世界创作者经济 | 平台经济与创作者侧概念之间的桥 |
| 创作者收入策略 | 表达分成方案与结算规则 |
| 桌面端钱包 | 把上述内容呈现给创作者 |

规范权威在 Realm 层；创作者侧的概念表面承载分成方案和收入策略。

## Append-Only 收入事件

每一条收入事件都是强类型的，并以追加方式入账。

| 事件种类 | 用途 |
| --- | --- |
| Gift | 发送方赠送内容或参与权 |
| Purchase | 买家购买已准入的可拥有资产 |
| Settlement | 按分成方案进行的周期性结算 |
| Withdrawal | 创作者把已结算资金提现 |
| Correction | 在准入的更正流程下覆盖前一条事件 |

Append-only 是审计的基础。每一条收入事件都带来源、时间戳和强类型形状。结算事件会引用它结算的那些 gift / purchase 事件。

## 分成方案

分成方案声明收入如何在创作者和贡献者之间切分。

| 属性 | 值 |
| --- | --- |
| Plan id | 稳定标识 |
| Owner | 编写该方案的创作者 |
| Splits | 强类型分配比例 |
| 生效时间 | 该方案适用的时间区间 |
| 版本 | 新方案覆盖旧方案，不会无声覆写 |

如果创作者要修改自己的分成方案，做法是发布一份新方案；旧方案被取代，但不删除。

## 桥接映射

`world-creator-economy.md` 和 `creator-revenue-policy.md` 是**桥接**文件。它们把外部开放规范锚点（"创作者经济"或"收入策略"这类宽泛概念）映射到本地的 Realm 经济契约上。

| 桥接 | 用途 |
| --- | --- |
| 世界创作者经济 | 创作者经济概念的领域桥 |
| 创作者收入策略 | 收入策略的领域桥 |

桥接文件让外部心智模型能对接进来；规范权威仍归 kernel 的 `R-ECON-*` 规则。

## 场景：创作者收到礼物收入

某个用户在创作者的世界里赠送内容；收入按方案结算给创作者。

1. **Gift 事件**。发送方的 gift 入账到经济事件流。发送方的钱包余额减少。
2. **触发结算**。按当前生效的分成方案，结算被排程或即时计算。
3. **结算事件入账**。各方分成入账；每位创作者的钱包派生视图更新。
4. **审计链路**。发送方 → gift 事件 → 结算事件 → 每位创作者的结算记录，全链可走。
5. **创作者查看**。在桌面端钱包里，创作者看到"通过 gift 事件 Y、按分成方案 Z 收到金额 X"。

整条链都可以重建。一个创作者要弄明白"为什么收到了这笔钱"，可以沿事件流回溯。

## 场景：一次提现

创作者要把已结算资金取走。

1. **提交提现**。创作者按准入的提现流程发起。
2. **Realm 校验**。余额是否充足、提现目的地是否准入等。
3. **提现事件**。强类型事件入账；余额按提现金额减少。
4. **外部结算**。资金在 Realm 之外，按准入的提现机制流向创作者的外部账户。

提现事件本身是 Realm 的规范真相。把资金转出去的外部机制是另外一份准入面，不属于 Realm 核心真相。

## 场景：更新分成方案

创作者更新分成方案，新增一位贡献者。

1. **编写新方案**。创作者写一份包含新贡献者的分成方案。
2. **发布**。Realm 准入新方案；旧方案按生效时间被取代。
3. **未来结算适用新方案**。从新方案的生效时间起，结算按新比例切分。
4. **历史结算不变**。已经入账的结算沿用当时的方案，不被回写。
5. **审计链路**。旧方案 + 新方案 + 取代事件全部入账。

分成方案是规范层数据；更新它会保留历史。

## 创作者经济不做的事

| 关注点 | 不做的原因 |
| --- | --- |
| AI 算力成本核算 | 是 runtime 侧的另一个关注点，不属 Realm 核心真相 |
| 世界内自定义货币 | 创作者可在自己的世界里跑内部货币，但那不是平台规范经济 |
| 订阅处理器内部细节 | 归在准入的订阅面，不归创作者经济直接管 |
