# 创作者经济与价值流转体系（Creator Economy）

创作者经济（Creator Economy）是 Realm 经济体系中专为数字世界创作者、模型设计者与艺术贡献者打造的价值激励与变现基础设施。它规定了数字内容如何确权、收益如何自动归因与切分，以及资金如何安全结算与提现。

关于底层金融级支付与提现管线的技术实现，请参阅[创作者收益与结算流水](/zh/realm/creator-payouts)。

> 状态说明：底层 `R-ECON-*` 经济事件账本规范与分成模型已确定；创作者收益提现管线及桌面端提现界面属于已立项的平台演进方向，当前并非公开 App API 或已上线的桌面端“财务中心”功能。

## 创作者经济的分层架构

| 架构层级 | 管辖范围 | 核心职责 |
| --- | --- | --- |
| **Realm 经济核心（`R-ECON-*`）** | 仅追加（Append-Only）事件流 | 记录真实的资产买卖、分成结算与提现流水账本 |
| **世界创作者经济规范** | 创作者侧的版权确权与衍生授权契约 | 规范虚拟世界场景、道具与虚拟形象的知识产权归属 |
| **收益策略与分成方案（Revenue Policy）** | 声明具体的商业化规则与分成比例 | 约定团队创作者与多协作者之间的收益分成方案 |
| **桌面端创作者工作台（规划中）** | 创作者数据看板与财务视图（平台方向） | 用于呈现销售分析、结算流水明细与提现意向的界面设计规划 |

## 仅追加式收入事件流

平台上的所有经济往来均通过结构化的事件流不可篡改地记录：

- **购买事件（Purchase）**：用户在数字世界或应用商城中购买创作者发布的数字资产；
- **结算事件（Settlement）**：系统根据预先约定的分成方案自动计算并划拨各协作者的应收份额；
- **提现事件（Withdrawal）**：创作者将已结算的收益通过平台提现流程提取至合规账户；
- **冲正事件（Correction）**：若发生退款或因系统故障需要调账，系统以追加冲正记录的形式替代原条目，杜绝修改历史账单。

## 多协作者分成方案（Revenue Splits）

支持单个作品或世界由多位创作者联合开发并共享收益：
- **方案标识明确**：每个分成方案拥有唯一稳定的 Plan ID，绑定明确的生效时间区间；
- **多方自动分配**：支持按百分比精确分配（例如世界总作者 70%、3D 建模师 20%、音效设计师 10%）；
- **版本可追溯**：若更新分成方案，新方案仅对生效时间点之后的后续交易所产生的分成起效，绝不追溯修改已经完成的历史结算。

## 规划流程：创作者收益结算与提现（平台设计方向）

1. **查看可提现余额**：创作者查看由 Realm 账本事件实时派生的已结算可用余额；
2. **提交提现申请**：通过平台受控的提现渠道发起申请，指定提现金额与受支持的结算通道；
3. **资金安全划拨**：平台自动记录 `Withdrawal` 提现事件并冻结对应额度，经合规审查后执行打款；
4. **全链路回溯**：每一笔提现记录均可穿透追溯至最原始的每一笔用户购买事件，实现完整的财务审计追踪。
