# 安装与可用性

Nimi 不止一个公开面。平台部分目前主要是产品与架构介绍，没有面向终端用户的整套安装命令。Nimi Coding 是个例外：它已有 npm 包 `@nimiplatform/nimi-coding`。

## 应该读什么

平台层先讲清楚产品模型。可以从架构页开始：

- [平台](/zh/platform/) — 世界模型与基础协议。
- [Runtime](/zh/runtime/) — AI 执行基础层是什么、它拥有什么。
- [SDK](/zh/sdk/) — 应用接入面。
- [桌面端](/zh/desktop/) — 原生外壳与它和网页端的差别。
- [Nimi Coding](/zh/nimicoding/) — 高风险变更走的治理工作流。

如果你想把 Nimi Coding 用在另一个项目里，看 [Nimi Coding 安装](/zh/nimicoding/installation)。

如果你在跟踪项目准备度，[规范地图](/zh/reference/spec-map)是查看哪些权威面已就位、哪些还在等准入证据的最直接入口。
