# Nimi 文档

Nimi 是一个 AI 开放世界平台。产品想法不绕弯：AI Agent 不该只是一次请求里的无状态工具。它可以驻留在长期存在的世界里，带着身份、记忆、关系、能力和规则，跨会话、跨表面延续。

这套文档讲清楚产品模型、归属边界，以及跨域成立的契约。

## 文档结构

Nimi 是一个开放世界平台。平台内含多个产品，共同让 AI Agent 能够在长期世界里生活：平台（世界模型本身）、Runtime（AI 执行）、SDK（App 接入）、桌面端与网页端（用户表面）、Realm（世界真相）、Avatar（形体呈现）、Cognition（记忆与知识）、Nimi Coding（与之同行的 AI 开发方法论）。

每个产品在文档里各自有一节。

仓库的 `apps/` 目录里有几个 extension app（parentOS、Forge、shiji、overtone 等），它们演示平台能做什么，但不是平台的一部分。这套文档不写它们，只描述平台。

## 三层视角

平台分三层。把它们分开看比混在一起想更清楚：

```
+----------------------------------------------------------+
|  平台模型                                                 |
|    World、Agent、六项固定基础协议                          |
+----------------------------------------------------------+
                          |
                          v
+----------------------------------------------------------+
|  执行底座                                                 |
|    Runtime    : provider、工作流、流式、                  |
|                 多模态、委派                              |
|    Cognition  : 记忆、知识、prompt 服务、                 |
|                 完成关卡                                  |
+----------------------------------------------------------+
                          |
                          v
+----------------------------------------------------------+
|  公开表面                                                 |
|    SDK App 边界           桌面端原生外壳                   |
|    网页端受限改写         Realm 公开读路径                 |
|    Avatar 形体权威                                        |
+----------------------------------------------------------+
```

1. **平台模型** 定义世界、Agent、六项固定基础协议，以及谁有权重定义什么的规则。
2. **执行底座** 是 AI 工作真正发生的地方：Runtime 持有 provider、工作流、流式、多模态输出、本地路由；Cognition 持有记忆、知识、prompt 服务、引用、完成。
3. **公开表面** 把平台呈现为桌面端、网页端、SDK、Realm、Avatar 体验。每一层公开表面都有自己的权威边界，并在文档里独立成页。
