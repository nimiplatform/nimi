# 数字世界（Worlds）架构概览

数字世界（World）是 Nimi 平台核心的业务载体与交互场域。系统的各项底层能力与协议，均围绕数字世界的构建与漫游展开。

## 什么是数字世界

在 Nimi 中，数字世界是一个持久存在的虚拟空间：AI 角色常驻其中，剧情与故事随时间持续演进。每个世界拥有其创作者确立的独特世界观与交互规则、跨越单个会话的持久共享状态，以及一条忠实记录世界变迁的不可篡改历史。

置身于世界中的参与者（无论是真实人类用户还是 AI 智能体），并非由该世界单方创造：他们拥有全局唯一的持久化身份、社交关系网络与虚拟经济积累，并可以在所有数字世界之间自由漫游与沿用。

数字世界**不是**：
- **聊天室**：文字与语音对话仅是世界内的交互表面；世界是赋予对话背景与情境意义的完整场域。
- **单次跑团战役**：战役只是临时的玩法会话；即使没有玩家在线，世界依然在时间流中自主演进。
- **单一游戏关卡**：关卡是预先设定的有限剧本；世界是拥有独立运转规则与连续历史的数字空间。
- **单一独立应用**：应用仅负责呈现平台能力的某一个侧面；世界才是应用所映射的实体内容。

世界更像是一座具备严谨内在逻辑的微型宇宙：由创作者精心设定、由参与者共同丰富，并在时间线上持久演化。

## 数字世界承载的三大核心维度

每个数字世界在 Realm 中均由三个紧密协作但职责明确的维度构成。详情可参阅 [世界状态与历史变迁](/zh/platform/worlds/state-vs-history)。

| 核心维度 | 解决的核心问题 | 权威归口 |
| --- | --- | --- |
| **世界权威设定（Truth）** | 该世界的权威设定、基础契约、核心实体与法则（可通过授权发布版本演进） | Realm `R-TRUTH-*` |
| **世界即时状态（World State）** | 世界在此刻的共享客观呈现（实体位置、状态属性、关系阶段） | Realm `R-WSTATE-*` |
| **世界演进历史（World History）** | 世界是如何从最初状态逐步演进至当前状态的完整可审计轨迹 | Realm `R-WHIST-*` |

清晰划分这三大维度至关重要：缺失底层设定的世界将失去规则边界；缺失即时状态的世界无法呈现当下；而缺失演进历史的世界则失去了溯源过去的能力。

## 相邻的 Realm 业务支撑服务

围绕数字世界，Realm 还提供多项标准化的核心业务服务：

| 业务服务 | 架构用途与职责范围 |
| --- | --- |
| **直接私聊（Chat）** | 人类用户之间端到端规范化的私信会话、消息投递、已读状态与多端同步 |
| **社交图谱（Social）** | 跨场景好友关系网络与权限准入校验，作为私信与世界漫游的前提 |
| **经济系统（Economy）** | 创作者经济模型、虚拟资产结算与流通分成记录 |
| **资产与绑定（Asset & Binding）** | 世界包含的场景模型、道具资产及其在参与者身上的装配映射 |
| **空间漫游（Transit）** | 经由 OASIS 系统主世界实施的标准化跨世界单跳漫游协议 |

这些服务由 Realm 统一治理，使数字世界真正成为有温度、有秩序的栖息之所，而非冰冷的数据表。

## 业务场景：玩家造访数字世界

当你登录 Nimi 并进入好友创建的世界时：

- **统一身份认证**：你在该世界中使用的身份与在全生态中一致。世界接纳你进入，但无权重新定义你的核心账号。
- **资产与社交延续**：你的个人资产包、好友关系与信誉在此处无缝呈现且受官方保护，不会被随意篡改。
- **本地世界观生效**：该世界可以定义其专属规则（如使用特殊的虚拟货币、或者以 4 倍速推进昼夜）；这些规则在世界内部生效，绝不影响你在世界外部的真实资产与状态。
- **智能体互动与记忆私有**：你与世界内角色的对话自然延续；角色的长期记忆由 Cognition 系统按 LocalAgent 独立私有存储，经由 Runtime 安全调用，不会泄露为公开的世界全局状态。
- **空间漫游中继**：当你离开前往下一个世界时，系统通过 OASIS 枢纽进行单跳漫游，确保跨场景状态迁移的安全可控。

## 业务场景：创作者发布数字世界

当你作为创作者完成一个世界的构建并准备面向公众开放时：

- **确立世界设定**：你设定世界观公理、常驻角色、初始场景、视图呈现与发布规则。
- **原子化发布（WorldRelease）**：通过事务性操作完成发布，一次性固化世界设定、场景资源与版本包；若需变更，系统支持标准化的版本迭代与回滚机制。
- **独立的内部经济体系**：你可以设计专属于该世界的内部道具交易规则，同时平台底层的通用结算体系依然安全解耦运行。
- **接入全球漫游网络**：发布完成后，世界正式成为 Nimi 漫游网络中的有效目的地，全球用户均可通过 OASIS 枢纽造访体验。
