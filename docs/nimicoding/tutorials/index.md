# Tutorials

Learning-oriented step-by-step lessons for Nimi Coding. Each
tutorial assumes prerequisites, walks the reader through a
specific outcome, and ends in a known state.

For problem-shaped recipes (you know what you want, you need a
"how"), see [How-to](/nimicoding/how-to/).

## Available Tutorials

| Tutorial | Outcome |
| --- | --- |
| [From Project To Governed Execution](/nimicoding/tutorials/project-to-governed-execution) | You go from install to `.nimi/spec/**`, topic admission, sweep audit, sweep design, and long-running Codex execution |
| [First Topic Bootstrap](/nimicoding/tutorials/first-topic) | You bootstrap Nimi Coding into a project and adopt `.nimi/**` |
| [First Wave End-To-End](/nimicoding/tutorials/first-wave-end-to-end) | You run a full topic / wave / packet / preflight / audit / closeout cycle on a small sample task |

## Tutorial Vs How-to

A tutorial answers "I want to learn." A how-to answers "I want
to solve a specific problem." If you already know what you're
trying to do, the [how-to recipes](/nimicoding/how-to/) are
shorter and more direct.
