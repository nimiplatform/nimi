# Tutorials

Learning-oriented step-by-step lessons for Nimi Coding. Each
tutorial assumes prerequisites, walks the reader through a
specific outcome, and ends in a known state.

For problem-shaped recipes (you know what you want, you need a
"how"), see [How-to](/nimicoding/how-to/).

## Available Tutorials

| Tutorial | Outcome |
| --- | --- |
| [Verify The Nimi Governance Setup](/nimicoding/tutorials/project-bootstrap) | You verify host ownership, project truth, projections, and retained skills |
| [Run A Governed Codex Project](/nimicoding/tutorials/project-to-governed-execution) | You combine Codex-owned execution with spec reconstruction, scoped gates, and real evidence |

## Tutorial Vs How-to

A tutorial answers "I want to learn." A how-to answers "I want
to solve a specific problem." If you already know what you're
trying to do, the [how-to recipes](/nimicoding/how-to/) are
shorter and more direct.
