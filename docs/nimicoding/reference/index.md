# Nimi Coding Reference

field listing or table; none narrate.

For narrative, see the paradigm pages and the
[governed Codex tutorial](/nimicoding/tutorials/project-to-governed-execution).

## How To Read

Reference pages are dictionary, not lessons. They assume you
already know the concept and want to look up exact fields, valid
enum values, or schema constraints.
