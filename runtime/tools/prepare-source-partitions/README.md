# Prepare a stopped Runtime source index for the current partitioner

From the Nimi root, `pnpm runtime:prepare-source-partitions --db /absolute/path/to/memory.db` inspects the canonical source snapshots, their column/provenance bindings, and the newly derived optional partition. The default operation is read only. A changed binding prevents optional source bodies from being served under the old index identity.

For a reviewed pre-release installation, stop its Runtime and take the normal full backup. Run the same command with `--output /absolute/new/staged.db --expected-input-hash <reviewed hash> --confirm-runtime-stopped`. It creates a new private SQLite file and verifies it. Only the derived partition inside affected snapshots changes in this copy. The original file is never replaced. Inspect the staged file and its plan (zero remaining changes) before any separately authorized installation. Keep the stopped database and its WAL/SHM generation together during any handoff. The normal Cognition owner rebuilds its derived corpus from the bound immutable source at startup.
